# Submission Checklist

## Preparation status

Product brainstorming and stack selection have been completed. Documentation and issue drafts have been prepared. Code, live GitHub issues, implementation, and QA have not yet been completed.

## Before implementation

- [x] Preserve the real brainstorming conversation.
- [x] Save the product specification.
- [x] Compare and select the technology stack.
- [x] Prepare the initial backlog.
- [x] Prepare agent, process, role, testing, design, and route documents.
- [ ] Record the exact course deadline and timezone.
- [x] Create or select the actual public GitHub repository: https://github.com/allfocusSS/studytrack.
- [ ] Push the preparation documents.
- [ ] Create all six actual MVP issues and record their links.
- [ ] PM-groom the next live issue.

## Before submission

- [ ] Every counted issue was opened before the deadline.
- [ ] Each issue has observable acceptance criteria and implementation evidence.
- [ ] Each issue has an independent QA PASS against the reviewed commit.
- [ ] All counted issues were closed before the deadline.
- [ ] All reviewed code and documentation are pushed.
- [ ] The full test suite and required Django checks pass on the final commit.
- [ ] A fresh clone follows README successfully.
- [ ] Two accounts demonstrate that assignment data is private.
- [ ] The transcript and all required Markdown documents are visible.
- [ ] No credentials, development database, or virtual environment is committed.
- [ ] Submit the public repository link.

Update checkboxes only after the corresponding action was actually completed. A local draft does not satisfy a live issue requirement.
